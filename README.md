# Telephone-directory

A **full-stack web application** designed to digitize and simplify employee contact management. The system provides a centralized interface to **search, view, add, update, and delete employee telephone records** efficiently.

The application uses **Node.js and Express.js** for backend API development, **HTML, CSS, and JavaScript** for the frontend, and an **Excel workbook** for data storage.

## Key Features

*  **Smart Search** – Search employees by name, department, phone number, extension number, or house number.
*  **Employee Directory** – View employee records in a structured and searchable table.
*  **Role-Based Access** – Separate Admin and Regular User access.
*  **Add Records** – Admins can add new employee details.
*  **Update Records** – Existing employee information can be modified.
*  **Delete Records** – Admins can remove outdated records with confirmation.
*  **Employee Count** – Displays the total number of directory records.
*  **Input Validation** – Validates employee information before submission.
*  **Dark Mode** – Light and dark theme support.
*  **Responsive UI** – Clean dashboard-style interface designed for usability.

The frontend communicates with the backend through APIs, while the backend handles searching, authentication, and CRUD operations on the Excel data.

##  Project Highlights

The project focuses on converting a manually maintained employee directory into a **searchable digital system**. Smart search enables quick contact lookup, while role-based access allows administrators to maintain records without giving modification privileges to regular users.

The Excel-based approach keeps the application lightweight while demonstrating practical **file handling, JSON conversion, API integration, validation, and CRUD implementation**.
